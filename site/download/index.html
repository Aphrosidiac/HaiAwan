build it from source

the mac app, its server and this website are all on github under the mit license. clone it, put your own openrouter key in server/.env, then start the server and build the app. the readme has every step.

git clone https://github.com/Aphrosidiac/HaiAwan.git
cd HaiAwan/server && cp .env.example .env
npm install && npm run migrate && npm run dev
cd ../app && ./scripts/fetch-codex.sh
./scripts/build-app.sh && open build/Awan.app
open on github
